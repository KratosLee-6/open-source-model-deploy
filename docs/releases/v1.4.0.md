# v1.4.0 (2026-10-31)

> 真实成本对比：本地一次性投入 vs 云租月费 + 回本周期。
> **每个价格带出处和采集时间，云租给区间不给单点，没报价的卡不编数字。**

上一版的 `budget` 有个根本问题：它按 `size_b` 拍档位，而不是按**实际显存需求**，
而且价格来自一张没有出处的「2026-08 基线表」。客户拿这个去做采购决策，
等于用一个来源不明的数字替换另一个来源不明的数字。

这一版重写成本模型。

## 🔍 「真实」体现在四个地方

### 1. 显存需求不再靠参数量拍脑袋

复用 `vram_requirements.suggest_gpu_plan()` —— 和「能不能跑」同一个来源。
6.4GB 需求 → 单张 4090；493.5GB → 7×A100。MoE 按**总参**算（v1.0.3 修过的坑）。

### 2. 云租给区间，不给单点

同一张 4090 的真实价格是散的：

| 来源 | 价格 |
|---|---|
| AutoDL 现货价 | ¥1.88/h 起（北京时间 0–6 点最低） |
| AutoDL 按需价 | ¥2.68/h |
| 第三方 4550 条样本中位 | ¥2.20/h |

抹成一个数字就是骗人。所以输出 `¥1.88–2.68/h` 区间，并注明每个数字来自哪。
A100 80G 同样：AutoDL ¥4.0–5.98/h · 阿里云 PAI ¥8–12/h · 腾讯云 TI ¥7.5–10/h。

### 3. 每个价格带出处 + 采集时间

```
"price_source": "2026-08 国内电商基线（hardware_prices.py）", "price_as_of": "2026-08"
"source": "AutoDL 价格页（按需 ¥2.68/h）+ 现货 ¥1.88/h 起", "as_of": "2026-07"
```

测试会强制检查：**没有 `source` / `as_of` 的条目直接测试失败**。

### 4. 没报价就不编

RTX 5090 / H100 / H200 / 昇腾 910B 在已知云平台**没有公开报价** ——
`_cloud_candidates()` 返回空列表，回本周期输出「无公开报价，无法算」，
而不是拿一张邻近卡的价格凑数。

---

## 🧮 回本周期的方向性（这里差点写反）

云租**越贵** → 本地回本**越快**。所以两个数不能混：

```
云租便宜档 ¥1,372/月 → 本地 18,200 ÷ 1,372 = 13.3 个月回本（慢）
云租贵档   ¥1,956/月 → 本地 18,200 ÷ 1,956 =  9.3 个月回本（快）
```

初版渲染成 `回本 13.3–9.3 个月`，数值对但违反直觉（大数在前）。
改成 `months_min` / `months_max` 后输出 `回本 9.3–13.3 个月`。
测试 `test_breakeven_direction_is_correct` 锁住这一点。

## 🧪 测试守的是什么（27 个）

| 组 | 守的东西 |
|---|---|
| 数据表完整性 | 每张本地卡必须有 `price_source` + `price_as_of` + 功耗；每个云价必须是区间且 `spot_low ≤ ondemand_high` |
| 卡型选择 | 6.4GB→单 4090 · 55GB→A100 · 100GB→5×4090 · 493.5GB→7×A100（24GB 超 8 张改 80GB）· 显存 0 报错 |
| 主流程 | 整机 = 卡价×数量×1.3 · MoE 按总参 · 电价参数生效 · `hours_per_month` 单档模式 |
| **方向性** | `months_min ≤ months_max` 且 min 确实来自云租贵档 |
| **不编数字** | 5090/H100/H200/昇腾 `_cloud_candidates()` 必须返回空；此时 breakeven 给 `note` |
| 口径 | `caveats` 必须含「运维」和「总拥有成本」 |

## ⚠️ 口径限制（输出里也会打印）

1. **只算硬件账**：不含运维人力、网络带宽、存储、机房/电费基础建设、折旧残值。
2. **本地整机按 GPU ×1.3 估算**（含主板/CPU/内存/硬盘/电源/机箱），不是精确报价。
3. **电价默认 ¥0.8/度**（中国商业用电常见 ¥0.6–1.2），可用 `--electricity` 覆盖。
4. **云租价会变**：现货价随时段波动，促销也常有。下单前以官网为准。
5. **回本周期 ≠ 总拥有成本对比**：它只回答「硬件钱多久靠租省回来」。
6. **本地卡价是 2026-08 基线**，没有月度自动刷新（这是下一步：接京东/淘宝真实报价）。
