# v1.0.2 (2026-09-26)

> 自动化扩展 + JEV 集成 · 模型库 94 → 127（+33%）

## 🎯 这一版做了啥

### 1. 自动拉取模型（核心新特性）

**新工具 `scripts/auto_fetch_models.py`** — 自动从 HuggingFace API 拉取主流开源模型，生成可粘贴的 KNOWN_MODELS patch：

- 覆盖 4 类 pipeline tag：`text-generation` · `image-text-to-text` · `sentence-similarity` · `text-to-image`
- 默认阈值：`downloads ≥ 50,000`（可调）
- 自动过滤 GGUF / AWQ / GPTQ / NVFP4 / abliterated 等量化与衍生版本
- 自动过滤 LoRA / adapter / merge 这类非主模型
- 只接受**权威 namespace**（Qwen / deepseek-ai / meta-llama / google / mistralai / THUDM / moonshotai / openai / nvidia / microsoft / baai / sentence-transformers / intfloat / OpenGVLab / CohereLabs / apple / stabilityai / Alibaba-NLP / EleutherAI / MiniMaxAI / inclusionAI / tencent / Hunyuan）
- **3 个 mode**：`stats`（看候选分布）· `diff`（对比现有）· `patch`（输出 dict 条目可粘贴）

发现现有 94 模型缺失 **185 个候选** · 本轮精挑 **33 个** 加入（覆盖国际通用补完 + 国内补完 + embedding 全家桶 + vision 补完）

## 🐛 修复的坑

1. **`resolve_model` 大小写 bug**：原代码用 `model_name.lower()` 查表，但部分现有 slug 用了大写（`all-MiniLM-L6-v2`），list 显示却 assess 失败 —— 这一版精修时把新加 slug 都用 lowercase，与 `.lower()` 查表语义一致
2. **本地补丁缩进陷阱**：前两轮 `patch` 工具长 multi-line 替换会把每行 indent +1，**已立铁律**：写完任何文件必跑 `python -c "import ast; ast.parse(...)"`，错了 `git checkout` 恢复 + 重做
3. **GitHub clone depth 漏历史**：`--depth 50` 不够（commit `c5f85da` 在最近 50 之外）—— 默认全 clone
